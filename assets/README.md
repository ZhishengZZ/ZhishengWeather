# README assets

This directory contains images used by the repository README. They are not packaged in the Android app.

- `screenshot-home.jpg` — current conditions, alert, hourly forecast, and precipitation
- `screenshot-details.jpg` — telemetry and air quality
- `screenshot-cities.jpg` — saved cities
- `screenshot-add-city.jpg` — empty state and city entry point
- `screenshot-settings.jpg` — data source, location, and unit settings
- `banner.png` and `icons_grid.png` — older project artwork kept for reference

The v0.0.2 screenshots are normalized to 720 x 1440 pixels. Device status bars and embedded photo metadata are not included.
